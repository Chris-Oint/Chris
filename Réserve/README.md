# Réserve

Copie autonome des ressources de l’application publiée `../index.html`.

## Organisation

- `bible/` — Bible complète et index de reconstruction.
- `brochures/` — 1 595 brochures réparties dans 5 zones JSON autonomes.
- `references-croisees/` — fichiers validés de références croisées et paquet ZIP d’intégration.
- `FICHE-RECONSTITUTION-REFERENCES-CROISEES.md` — modèle précis pour reconstruire les liens Bible ↔ paragraphes.
- `INVENTAIRE.json` — comptages, provenance et contrôle d’intégrité.

Le contenu de l’application à la racine du dépôt n’est pas déplacé ni modifié. Cette réserve est une copie séparée des données, destinée à orienter une future reconstruction ou une autre application.
